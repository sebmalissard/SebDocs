# Windows

## Startup application

To run your application automatically at startup, add it (or a shortcut to it) in this folder:
```
Windows + R
shell:startup
```

Example path:
```
C:\Users\Seb\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
```

Example shortcut target:
```
C:\Users\Seb\AppData\Local\Microsoft\WindowsApps\pythonw.exe "C:\Users\Seb\Documents\my-toolkit\scripts\sync_torrent.py"
```
